# Webprofil

Next.js 16.2.6 und React 19.2.4 stammen aus der aktualisierten Frühjahrsvorlage. Das Profil reduziert deren aktive Abhängigkeiten auf den neutralen Webkern, TypeScript und Playwright. Konkrete geprüfte Auflösung steht im package-lock.json.

Es gibt weder Beispielrollen noch fachliche Tabellen, Authentifizierung oder ein vorgefertigtes Unternehmensdesign. Bootstrap erzeugt nur Titel, Beschreibung und Health-Identität. Der Agent ergänzt das Projekt anhand der vereinbarten Unterlagen.

Optionale Fähigkeiten: Persistenz kann beispielsweise mit Prisma und SQLite, Auth mit Better Auth ergänzt werden. Ihre Integration ist in dieser Preview nicht als getesteter Baukasten enthalten. Versionen und Verbindung müssen beim tatsächlichen Bedarf geprüft werden.
